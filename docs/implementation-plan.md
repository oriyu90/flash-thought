# 実装計画

## 技術構成

- Kotlin / Jetpack Compose / Material 3
- Navigation Compose による Home、Quiz、Result の画面遷移
- DataStore Preferences による直近成績の永続化
- `HorizontalPager` による3画像の横スワイプ
- 画面の幅（600dp以上）と向きによる縦横・大画面レイアウトの切替

## 実装順

1. Android プロジェクト、ダークテーマ、依存関係を構成する。
2. 教材から10項目×3枚を `res/drawable-nodpi` へ取り込み、カード定義を作る。
3. ホーム、出題、答えオーバーレイ、結果画面と状態管理を実装する。
4. 成績保存と復元を実装する。
5. Compose のUIテストで10問完走、結果保存、ホーム表示を確認する。
6. Gradle ビルドと静的検査を行う。

## 受入条件

- ホームから開始し、10問を評価して結果まで到達できる。
- 1問につき3画像を横スワイプでき、答え表示はフェードを伴う。
- 正誤の集計が正しく、直近成績としてアプリ再起動後も残る。
- 縦・横画面で操作が隠れず、主要ボタンが48dp以上である。
