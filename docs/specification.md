# 記憶カード 仕様書

## 目的

画像を見て物の名前を思い出す10問のフラッシュカードで、記憶の想起を気軽に練習できる Android アプリを提供する。

## 対象とデータ

初版では、教材フォルダにある各3枚の画像を利用し、次の10項目を1セッションに出題する。

1. パプリカ
2. バレーボール
3. 鉛筆
4. ボールペン
5. 色鉛筆
6. リモコン
7. エアコン
8. ガスコンロ
9. トースター
10. 洗面器

出題順は毎回ランダムとし、各設問では同一項目の3画像を横スワイプで確認できる。

## 画面と操作

### ホーム

- 「フラッシュカードを始める」ボタンを大きく表示する。
- 端末内に保存した直近セッションの正答数、問題数、正答率、実施日時を表示する。初回は未実施として表示する。

### 出題

- 進捗（例: 3 / 10）と画像ページの位置を表示する。
- 画像は横ページングで3枚を切り替える。
- 「答えを見る」で答え表示へ進む。

### 答え表示

- 画像面に半透明のスクリーンをフェードインし、物の名前を大きく表示する。
- 「正解だった」「もう一度」の2択を大きなタップ領域で表示する。
- 選択後は次問へ進み、10問目後は結果画面へ進む。

### 結果

- 正答数、全10問、正答率を大きく表示する。
- 「ホーム」と「さらに解く」を表示する。
- 成績を DataStore に保存し、ホームの最近の成績へ反映する。

## UI / アクセシビリティ

- 常時ダークテーマ、Material 3 を採用する。
- 読みやすさを優先し、見出し・ボタン・選択肢を大きくする。操作対象の最小サイズは48dpとする。
- 画像には項目名を内容説明として付ける。装飾アイコンには内容説明を付けない。
- 端末のフォントサイズ設定と画面幅に追従する。
- 縦画面は画像の下に操作群を置く。横画面または横幅600dp以上は、左に画像、右に進捗・ボタン・回答操作を置く。
- システムの戻る操作は答え表示中なら答えを閉じ、出題中ならホームに戻る。

## 初版の非対象

- 問題セットの編集、クラウド同期、ユーザー登録、音声読み上げ、詳細な履歴一覧。
