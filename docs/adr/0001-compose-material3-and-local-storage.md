# ADR 0001: Compose / Material 3 と端末内成績保存を採用する

- 状態: 採用
- 日付: 2026-09-29

## 背景

本アプリは大きな文字と操作領域、ダークモード、縦横の適応表示、短い画面フローを必要とする。最近の成績はオフラインでも表示する必要がある。

## 決定

- UI は Jetpack Compose と Material 3 で実装する。
- テーマはアプリ固有の高コントラストなダーク配色を固定で用いる。
- 画面適応は Compose の画面幅（600dp以上）と画面の向きで行う。
- 直近セッションのみを DataStore Preferences に保存する。
- 問題画像はネットワーク取得せず、APK の drawable リソースとして同梱する。

## 理由

Compose は状態に応じた「出題→答え→採点→結果」遷移と、画面サイズ別レイアウトを簡潔に扱える。Material 3 は大きなコンポーネントとアクセシビリティに適し、DataStore は小さな設定・成績データに対して軽量で安全である。画像同梱により通信なしで確実に練習できる。

## 影響

- 初回インストール時に画像分のAPKサイズが増える。
- 複数回の履歴や分析が必要になった場合は Room への移行を検討する。
