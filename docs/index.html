フラッシュ思考

画像を見て、ものの名前を思い出そう。

10問のフラッシュカードで、記憶の想起を気軽に練習できる Android アプリです。オフラインで動作し、端末内に成績を保存します。

ダウンロード

最新版: v1.0.0（Android 8.0 以降）

APK をダウンロード

インストール: 設定 → セキュリティ → 提供元不明のアプリを許可してから APK を開いてください。

特徴

  • 10項目 × 3枚の画像を横スワイプで確認
  • 常時ダークテーマ / Material 3
  • 縦・横画面の両方に適応
  • 直近の成績を端末内に保存
  • 通信不要・完全オフライン

使い方

  1. 「フラッシュ思考を始める」をタップ
  2. 画像を見てものの名前を思い出します
  3. 「答えを見る」で答えを確認
  4. 「正解だった」/「もう一度」で採点
  5. 10問終了後、結果画面で成績を確認
